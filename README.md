## 🌎 About The Project

**US.par – Travel App** is a web development project focused on creating an engaging travel platform with destination discovery and travel-related pages.

The application provides an organized interface where users can explore destinations, access booking-related pages and navigate account features.

The project focuses on responsive frontend development, user interface design and interactive website functionality.

## ✨ Features

- 🌍 **Destination Exploration:** Dedicated destination discovery page.
- 🏨 **Booking Section:** Travel booking-related interface.
- 👤 **User Authentication Pages:** Login and signup interfaces.
- 🔐 **Password Recovery:** Forgot-password page.
- ⚙️ **Settings:** Dedicated settings page.
- 📩 **Contact Page:** Contact-related interface.
- 📱 **Responsive Interface:** Designed for different screen sizes.
- 🎨 **Modern UI:** Travel-inspired visual design and navigation.

## 🚀 Getting Started

Follow these steps to run the project locally.

**1. Clone the repository**

```bash
git clone https://github.com/sarvadaanvekar17-bit/US.par-Travel-App.git
```

**2. Open the project folder**

```bash
cd US.par-Travel-App
```

**3. Run the application**

Open `index.html` in your browser or use the Live Server extension in Visual Studio Code.
